# Sistema de Loja de Roupas (Tkinter + JSON)

Aplicação desktop simples para gerenciamento de vendas e controle de estoque de uma loja de roupas.

## 📁 Estrutura do Projeto

- `main.py`: Ponto de entrada da aplicação.
- `interface.py`: Gerenciamento da interface gráfica (Tkinter).
- `dados.py`: Leitura e escrita do banco de dados local (`produtos.json`).
- `validacoes.py`: Regras de negócio e validação do carrinho e estoque.
- `dados/`: Pasta destinada ao armazenamento dos arquivos JSON.
- `evidencias/`: Pasta reservada para guardar prints, logs ou gravações do funcionamento.

## 🚀 Como Executar

1. Certifique-se de ter o Python 3.x instalado.
2. Clone ou baixe este repositório.
3. No terminal, acesse a pasta do projeto e execute:

```bash
python main.py
